Forecast GTA VI's launch-day Twitch viewers hour by hour: a deterministic, standard-library-only Python program that predicts the five scored quantiles for hours 2–24 from hour 1's print, using weighted empirical quantiles of the log-ratio profiles of past big launches that were already live at hour 1.

## Run it

```sh
python3 main.py
```

Locally against the kit's practice cases: `MAKEFUN_INPUT_DIR=<kit>/input MAKEFUN_OUTPUT_DIR=out python3 main.py`
